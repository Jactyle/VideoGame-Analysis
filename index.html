About this data

The data comes from the Steam Games Dataset maintained by Fronkon Games (MIT license), which is built directly from the official Steam store API and SteamSpy. One row is one published game on Steam: its release date, its developer and publisher, its genre and store category, which platforms it runs on, its price, its review counts, and Steam's own estimate of how many people own it. DLC, soundtracks, videos, and other non-game listings are already excluded by the source dataset.

From the source file's — usable rows, this analysis drops — rows: — pre-release "playtest" builds (not released games), — games with no genre listed at all (genre is used throughout this site as a filter and category), and one row with no game name. That leaves — games. The raw source file also had a header bug — a missing comma merged its "Discount" and "DLC count" columns into one — which the cleaning script corrects before anything else.

Every derived number on this site is computed the same way:

  • Release year is parsed from Steam's release-date string. Some games only list a month or a bare year; those are treated as January 1st of that year, so a handful of "years" are slightly imprecise about the month.
  • Review-positive rate for a single game is positive ÷ (positive + negative) reviews. For a group of games (a genre, a year, a platform) it is the sum of positive reviews across the group divided by the sum of all reviews in the group — a weighted rate, not an average of each game's own rate, so one blockbuster with millions of reviews properly outweighs thousands of unreviewed games.
  • Estimated owners is the midpoint of the owner range Steam/SteamSpy publish for each game (for example, "0 – 20,000" becomes 10,000). It is a rough estimate derived from public signals, not a verified sales figure, and is only meaningful in aggregate or in relative comparisons.
  • Median playtime for a group only includes games that report nonzero average playtime; games reporting zero are treated as missing data, not as "never played," since Steam doesn't distinguish the two.
  • Publisher is the first publisher listed for a game. When a game lists no publisher, its developer is used instead (469 games); when it lists neither, it's labeled "Unknown" (77 games).
